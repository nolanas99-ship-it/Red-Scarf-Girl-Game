RED SCARF GIRL: A REVOLUTION IN SHANGHAI
Playable browser game · build 1

HOW TO PLAY
1. Open index.html in a current desktop browser (Chrome, Edge, Firefox, or Safari).
2. Select “Begin a new story”.
3. Move with W/A/S/D or the arrow keys.
4. Walk near the red-highlighted objective and press E, or click a nearby person/object.
5. Press J to open the journal. Use the on-screen buttons for the journal, relationships, guide, settings, and save controls.
6. When asked to write a da-zi-bao, enter your own text, then choose whether to publish it or keep it private.

SAVE SYSTEM
Progress autosaves after major choices in this browser's local storage. Use Save for a manual save. Export save file downloads a portable JSON save; Import save file restores one.

WHAT'S INCLUDED
- Eight chapter campaign with 40 main objectives
- Walkable, locally rendered Shanghai neighborhood illustration
- Branching dialogue and consequence-tracking stats
- RP categories, including BLACK CATEGORY below 10 RP
- Separate family trust, peer trust, personal integrity, suspicion, and historical knowledge
- Interactive da-zi-bao composition, submission, private drafts, publication, and visible poster marks on noticeboards
- Journal, document archive, timeline, private reflections, save/load, import/export
- Responsive layout and controls help

HISTORICAL NOTE
This is an original interactive adaptation inspired by Ji-li Jiang's memoir, not a word-for-word reproduction. Some scenes and connective dialogue are fictionalized for gameplay. Interactive stats and reputation thresholds are game-design systems, not official historical classification rules. The build has not been independently verified as a three-hour playthrough; the campaign contains the requested chapter structure and systems, but its final duration depends on exploration and reading pace.

TECHNICAL
The game is self-contained: no external images, libraries, or network access are required. Keep index.html and README.txt together. If local saving is restricted by browser file policies, run it from a local static web server or use Export/Import save files.
